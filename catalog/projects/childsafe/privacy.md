# Privacy Policy for ChildSafe

*Last updated: June 10, 2026*

ChildSafe values the safety and privacy of families. This policy details how data is handled.

## 1. Purpose of Data Collection
ChildSafe collects data solely for parental monitoring and child safety. This includes location data, app usage logs, and system status.

## 2. Location Data
Real-time location data is collected to allow parents to locate their child. This data is transmitted securely to the parent's authorized account and is not shared with third parties.

## 3. Permissions
- **Device Admin:** To prevent unauthorized uninstallation.
- **Location:** To provide live tracking features.
- **Accessibility:** To monitor app usage and enforce time limits.

## 4. Security
All data transmitted between the child's device and the parental dashboard is encrypted using industry-standard protocols.
