# Privacy Policy for JitForge

*Last updated: June 10, 2026*

JitForge ("the Engine") is a high-performance in-memory runtime compilation, JIT execution, and bytecode synthesis engine.

## 1. No Data Collection
The Engine does not collect, store, or transmit user source code or compiled bytecode to external services. All tasks are performed in-memory.

## 2. Sandboxed Execution Safety
AST rule validators and SandboxedExecutor enforce execution safety and timeouts to reject forbidden APIs.
