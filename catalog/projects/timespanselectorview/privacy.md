# Privacy Policy for TimeSpanSelectorView

*Last Updated: June 25, 2026*

Welcome to **TimeSpanSelectorView**. This is an open-source Android UI library designed for Material 3 applications.

## 1. Zero Data Collection
- **In-Memory Processing:** All time range selection calculations occur strictly in-memory.
- **No Persistent Storage:** The library creates no database entries, files, or preference stores.
- **No Permissions:** Requires no system permissions (No Internet, Storage, or Location needed).

## 2. Open Source Transparency
Full source code is available on GitHub under the Apache 2.0 License with no hidden tracking or telemetry.
