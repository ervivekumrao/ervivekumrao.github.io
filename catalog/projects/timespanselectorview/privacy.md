# Privacy Policy for TimeSpanSelectorView

*Last updated: June 25, 2026*

Welcome to **TimeSpanSelectorView**. This is an open-source Android UI library designed to provide elegant radial and linear time range selection for Material 3 applications. We are committed to ensuring that our components are privacy-respecting and transparent.

## 1. Data Collection Disclosure
As a specialized UI component library, TimeSpanSelectorView is designed with privacy as a core principle:
- **Zero Data Collection:** The Library **does not** collect, store, or transmit any data from the host application or its users.
- **In-Memory Processing:** All time selection operations, calculations, and visual updates are performed locally within the host application's memory.
- **No Persistent Storage:** The library does not create local databases, files, or shared preference entries on the user's device.
- **No Permissions Required:** The library does not require any special Android permissions (such as Internet, Location, or Storage) to function.

## 2. Open Source Transparency
- **Auditable Code:** The full source code of the Library is publicly available for review on GitHub. Developers can verify the implementation to ensure it meets privacy and security standards.
- **No Hidden Tracking:** The library contains no hidden tracking codes, analytics engines, or third-party SDKs.
