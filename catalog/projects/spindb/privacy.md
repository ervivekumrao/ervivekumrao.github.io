# Privacy Policy for SpinDB

*Last updated: June 10, 2026*

SpinDB ("the Tool") is an open-source containerized database and lakehouse management CLI utility (`spinctl`).

## 1. Local Execution Only
The Tool operates entirely on your local machine using rootless Podman or Docker. It does not collect or transmit any database configurations, credentials, or machine telemetry to any external server.

## 2. Database Credentials & Ports
Any credentials configured or generated via command-line arguments are used solely to configure local container instances. These values are never shared or uploaded.

## 3. OCI Container Management
The Tool interacts with your local Podman or Docker daemon to manage container images and check OCI port healthiness following standard container runtime security protocols.
